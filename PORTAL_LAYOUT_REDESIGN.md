# HStaff UI Layout Redesign

This update changes the page structure and information hierarchy, not the colour theme.

## Customer dashboard
- New welcome/primary action area
- Separate booking metric strip
- Three quick-action cards
- Recent bookings as the main content area
- Booking progress and support in a secondary column

## Admin dashboard
- New operations header
- Six compact KPI tiles
- Two-column command centre
- Recent registrations as the primary work area
- Platform tools grouped in a grid
- Attention-required panel and admin shortcuts in the side column

## Worker portal
- Kept intentionally simple and mobile-first.
- No additional reading, forms, or complex navigation added.

Existing backend routes, authentication, database, shift workflow, and demo checkout have been retained.
