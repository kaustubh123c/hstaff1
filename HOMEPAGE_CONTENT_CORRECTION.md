# H-Staff homepage content correction

Updated the public landing page to describe H-Staff as a staffing and worker-management platform.

Removed inaccurate positioning and claims about multi-site contractor payroll, automated PF/ESIC, wage slips, payroll processing, GPS geofenced site attendance, and Razorpay/bank payouts.

Homepage now presents:
- Worker marketplace and worker discovery
- Scheduled shift creation and management
- On-demand worker requests
- Active job progress tracking
- Arrival and job-completion OTP verification
- Customer, worker and admin workflows

The dashboard preview is explicitly illustrative and avoids fabricated attendance totals or operational statistics. This update changes the public homepage presentation only; it does not add or promise new backend capabilities.
